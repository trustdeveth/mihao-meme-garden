`mihao-head.png` is the player's head texture, used by `tools/models/mihao.js`.

Its face is cut from a meme picture supplied for a local look test. **The rights to that picture have not been
checked.** Before releasing the game, get permission to use it or replace this file with artwork you have the
rights to (same layout: 1024 x 512, left half the face seen from the front, right half plain fur), then run
`npm run models -- --only farmer`.
